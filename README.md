# Triple Cleaning Website

Static public website for Triple Cleaning residential cleaning services.

## Local Preview

Open `index.html` in a browser.

## Publish

Netlify builds the site with `node tools/build-seo.cjs --publish` and publishes `dist/`. For a custom domain, configure `SITE_URL` with the official HTTPS origin. See [SEO maintenance](docs/seo.md) for indexing, domain configuration and validation.

## Booking Flow

Customers prepare a booking request, copy it, and send it by WhatsApp to `0892721358` for manual availability confirmation.
